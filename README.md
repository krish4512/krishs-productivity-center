# Krish's Productivity Center

A quiet desk for deep work: a to-do list and a pomodoro timer on one page.

**Live site:** https://krish4512.github.io/krishs-productivity-center/

Tasks persist in your browser. Space starts and pauses the timer.

This repository is the static GitHub Pages copy. The source files are `index.html`, `styles.css`, and `app.js`.
