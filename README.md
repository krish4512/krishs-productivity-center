# Krish's Productivity Center

A quiet desk for deep work: a to-do list that strikes tasks through as you finish them, and a pomodoro timer on the same page.

**Live site:** [krish4512.github.io/krishs-productivity-center](https://krish4512.github.io/krishs-productivity-center/)

## Features

- Add, complete, pin, and delete tasks
- Focus / short break / long break timer
- Auto-advance after four focus sessions
- Saved in your browser

Space starts and pauses the timer. Enter adds a task.
